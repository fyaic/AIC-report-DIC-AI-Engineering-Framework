# project-governance（运行器中立版）

执行角色：OD + PM。输出目录：`01_零号仓库/01_项目核准证 … 04_产品路标`。

## 执行步骤

1. 读 `01_零号仓库/README.md` + `tool-repo/07_公共模板库/02_零号仓库模板/`。
2. 按模板顺序产出四件套：
   - `01_项目核准证/01_项目核准证.md`（模板：01_项目核准证模板.md）
   - `02_项目环境/01_项目环境说明.md`（模板：02_项目环境模板.md）
   - `03_产品需求清单/00_产品需求池.md` + `VDL-vX.Y.Z_版本需求清单.md`（模板：03/07）
   - `04_产品路标/00_版本总表.md` + `VER-vX.Y.Z_版本卡.md`（模板：05/06）
3. 准入结论按事实填写：环境未就绪就写「否」并列补齐项，不美化。

## 新版本启动序列（后续版本复用）

`00_版本总表.md` 回写 → 建 `VER-版本卡` → 建 `VDL-版本需求清单` → 才进一号仓库。

## 输出契约

每份文档带 doc-gatekeeper 生成信息块；版本总表登记当前激活版本与分支。

## 禁止

1. 在零号仓库写方案/原型/PRD/实现正文。
2. 用会议纪要替代正式结论；未确认信息必须标「待确认」。
