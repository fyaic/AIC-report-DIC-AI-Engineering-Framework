# od-demand-analyzer（运行器中立版）

执行角色：OD。输出目录：`00_OD工作区/01_方法论…05_字典` 对应子目录。

## 输入

业务原始材料（访谈、会议纪要、操作指引）。OD 产物是**一号仓库的上游输入，不是正式需求真源**。

## 执行步骤

1. 读 `00_OD工作区/README.md` 与 `tool-repo/07_公共模板库/01_OD工作模板/`。
2. 从原始材料提取：业务方法论、To-Be 流程步骤、组织与角色、权限差异、领域字典（术语表）。
3. 每项产出注明来源文件与原话锚点，禁止无出处的推断。
4. 识别「规则断点」：材料之间口径冲突、未覆盖环节，登记到 `01_方法论/` 下附断点清单（供测试报告消费）。

## 输出契约

- `00_OD工作区/01_方法论/01_业务方法论输入.md`
- `00_OD工作区/02_To-Be流程/01_敏货看板To-Be流程.md`
- `00_OD工作区/05_字典/01_敏货领域字典.md`
- 断点登记表（含来源、冲突描述、需谁定夺）

## 禁止

1. 把 OD 输出直接当正式需求写入一号仓库正文。
2. 在 OD 工作区做方案设计或原型。
