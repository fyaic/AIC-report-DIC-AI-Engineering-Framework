# qa-execute（运行器中立版）

执行角色：QA 主写，PM 确认用例与验收结果。输出目录：`05_四号仓库/01_测试验收/vX.Y.Z/`。

## 执行步骤（按序）

1. 读 `05_四号仓库/README.md` + `tool-repo/07_公共模板库/06_四号仓库模板/01_测试验收模板/` + 产品基线。
2. **测试设计**：`01_测试设计/TC-NNN-*.md`——每用例：前置/步骤/预期/对应 FR；PM 确认用例清单。
3. **测试执行**：`02_测试执行/`——接口层用脚本执行（curl/pytest）；界面层用浏览器自动化按用例操作并截图留证；结果逐条登记（通过/失败/阻塞）。
4. **Bug 管理**：`03_Bug管理/BUG-NNN-*.md`——现象/复现/根因/责任仓（需求/设计/编码）；修复走代码仓，回归回本仓登记。
5. **产品验收**：`04_产品验收/`——PM 按验收标准逐项核对。
6. **测试报告**：`05_测试报告/`——用例统计、Bug 统计、风险残留。
7. **放行建议**：`06_版本放行与交付建议/`——放行/有条件放行/不放行 + 理由。

## 留证要求

界面用例执行必须存截图到本仓库或报告资产目录，文件名含用例号。

## 禁止

1. QA 用例未确认就执行验收。
2. Bug 不登记直接口头修复。
3. 测试报告美化未通过项。
